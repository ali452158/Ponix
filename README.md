# Ponix EA

إكسبيرت MT5 مخصص لمؤشر **PainX** (المؤشرات الاصطناعية - Weltrade).

## المواصفات (الإصدار 3.21)
- **صيد السبايك قبل الهبوط (جديد 3.21)**: عندما يصبح السبايك مستحقاً (العداد دخل نافذة الاستحقاق 1.05-1.60× المتوسط) يكفي أول علامة هبوط للدخول فوراً قبل الهبوط:
  - انقلاب الدقيقة الحالية هبوطاً (البيدي تحت افتتاحها) - إشارة واحدة لكل دقيقة
  - أو تيك هبوط عنيف
  - أو كسر قاع آخر شمعة خمس دقائق (InpBreakTF=PERIOD_M5)
- **المؤشرات الهابطة فقط (3.21)**: الإكسبيرت يعمل على عائلة PainX (المؤشر الهابط) ويرفض أي رمز آخر
- **قانون الانعكاس الواضح (3.18) خارج النافذة**: إذا لم يكن السبايك مستحقاً فلا بيع إلا بعد انعكاس سعري واضح على ربع الساعة (حي أو مكتمل) ثم الدخول مع أول الهبوط
- **بدون ستوب متحرك (3.20)**: أُلغي الستوب المتحرك وقفل التعادل نهائياً - الستوب ثابت عند -2$ لا يتحرك إطلاقاً
- **دورة إغلاق ودخول**: الصفقة تُغلق عند هدفها فقط (شراء +5$ / بيع +10$) أو عند ستوبها (-2$) ثم يدخل الصفقة التالية تلقائياً
- **ملف المخاطر (3.19)**: ستوب 2$ لكل الصفقات | هدف البيع 10$ | هدف الشراء 5$
- **اللوت مثبت 0.1 (3.16)**: حُذف مدخل اللوت نهائياً - كل الصفقات تُفتح بحجم 0.1 ثابت لا يتغير من الإعدادات
- بلا أي توقف: لا فاصل بين الصفقات، لا حد للصفقات اليومي، لا انتظار بعد الخسارة، لا حد خسارة يومي
- شراء الارتداد مفعّل: بعد إغلاق البيع ينتظر أول شمعة دقيقة صاعدة ثم يشتري بهدف 5$ | خروج الشراء أيضاً بعد 6 شمعات أو 6 شموع صعود متتالية

## التركيب
1. حمّل ملف `Ponix.mq5`
2. ضعه في مجلد `MQL5/Experts` في منصة MT5
3. افتح MetaEditor واضغط F7 للترجمة
4. اسحبه على شارت PainX وفعّل التداول الآلي

> تحذير: المؤشرات الاصطناعية عالية المخاطر. جرّب على حساب تجريبي أولاً.
